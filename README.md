## B2B Commerce

- [Adobe Commerce (Magento)](https://magento.com/) - Adobe Commerce is an enterprise e-commerce platform built on Magento, available as a cloud service or self-managed option. Magento Open Source is the free, self-hosted edition. It serves B2B and B2C merchants requiring extensive customization. ([Read more](/details/adobe-commerce-magento.md)) `Enterprise` `Self-Hosted` `API` `B2B` `PHP`
- [OroCommerce](https://orocommerce.com/) - OroCommerce is an open-source B2B e-commerce platform built for manufacturers, distributors, and wholesalers. It includes workflow management, customer-specific pricing, and CRM integration. A free community edition is available for self-hosting. ([Read more](/details/orocommerce.md)) `Open Source` `Self-Hosted` `B2B` `PHP` `Wholesale`
- [Salesforce Commerce Cloud](https://www.salesforce.com/products/commerce-cloud/overview) - Salesforce Commerce Cloud is an enterprise B2B and B2C e-commerce platform hosted on the Salesforce cloud. It includes AI-powered recommendations, order management, and omnichannel capabilities. Pricing is quote-based for enterprise customers. ([Read more](/details/salesforce-commerce-cloud.md)) `Enterprise` `Paid` `API` `B2B` `AI-Powered`

## Digital Products

- [Gumroad](https://gumroad.com/) - Gumroad is a platform for creators to sell digital products, memberships, and physical goods directly to buyers. It handles checkout, hosting, and file delivery with no monthly fee, taking a percentage of sales. It is aimed at individual creators and small sellers. ([Read more](/details/gumroad.md)) `Freemium` `Digital Products` `Creator Economy`
- [Lemon Squeezy](https://www.lemonsqueezy.com/) - Lemon Squeezy is a merchant of record platform for selling software and digital products globally. It manages checkout, taxes, subscriptions, and affiliate payouts. It charges transaction fees with no monthly subscription. ([Read more](/details/lemon-squeezy.md)) `Freemium` `Digital Products` `SaaS` `Merchant of Record`

## Headless Commerce

- [commercetools](https://commercetools.com/) - commercetools is a cloud-native, headless commerce platform built on MACH architecture. It provides APIs for product, cart, and order management across channels. It targets enterprise retailers and brands with usage-based pricing. ([Read more](/details/commercetools.md)) `Paid` `Enterprise` `API` `Headless` `MACH`
- [Medusa](https://medusajs.com/) - Medusa is an open-source headless commerce engine built with Node.js. It provides backend commerce logic and APIs for custom storefronts, with a plugin system for payments and fulfillment. It is self-hosted and free to use. ([Read more](/details/medusa.md)) `Open Source` `Self-Hosted` `API` `Node.js` `Headless`
- [Saleor](https://saleor.io/) - Saleor is a headless, GraphQL-first e-commerce platform built with Python and Django. It offers a storefront backend and admin dashboard, designed for high-growth businesses. The core platform is open source and self-hosted. ([Read more](/details/saleor.md)) `Open Source` `Self-Hosted` `API` `GraphQL` `Python`
- [Sylius](https://sylius.com/) - Sylius is an open-source e-commerce platform for PHP and Symfony, designed as a headless solution. It provides a decoupled backend with APIs and a customizable admin interface. The community edition is free and self-hosted. ([Read more](/details/sylius.md)) `Open Source` `Self-Hosted` `API` `PHP` `Symfony`
- [Vendure](https://www.vendure.io/) - Vendure is an open-source headless e-commerce framework built with TypeScript and Node.js. It features a GraphQL API, plugin architecture, and is designed for developers creating custom commerce experiences. It is self-hosted under an open-source license. ([Read more](/details/vendure.md)) `Open Source` `Self-Hosted` `API` `GraphQL` `TypeScript`

## Hosted E-commerce Platforms

- [BigCommerce](https://www.bigcommerce.com/) - BigCommerce is a hosted e-commerce platform for growing and enterprise brands. It offers built-in B2B and B2C features, multi-storefront support, and open APIs. Pricing is based on annual sales volume. ([Read more](/details/bigcommerce.md)) `Paid` `API` `Enterprise` `B2B` `Omnichannel`
- [Ecwid](https://www.ecwid.com/) - Ecwid is a hosted e-commerce shopping cart that can be embedded into existing websites or social media pages. It offers a free plan for up to five products and paid plans for larger inventories. It handles payments, shipping, and taxes. ([Read more](/details/ecwid.md)) `Freemium` `Hosted` `Embeddable` `SMB`
- [Shift4Shop](https://shift4shop.com/) - Shift4Shop is a hosted e-commerce platform formerly known as 3dcart. It provides website building, product management, and payment processing. A free plan is available for merchants using Shift4 payment processing. ([Read more](/details/shift4shop.md)) `Freemium` `Hosted` `Payment Processing` `SMB`
- [Shopify](https://www.shopify.com/) - Shopify is a hosted e-commerce platform for online stores and retail point-of-sale. It includes website builder, payment processing, and shipping tools. Pricing is subscription-based with tiered plans. ([Read more](/details/shopify.md)) `Paid` `API` `Hosted` `D2C`
- [Squarespace E-commerce](https://www.squarespace.com/ecommerce) - Squarespace is a hosted website builder with integrated e-commerce capabilities. It supports product sales, subscriptions, and inventory management through tiered subscription plans. Transaction fees apply on lower-tier plans. ([Read more](/details/squarespace-e-commerce.md)) `Paid` `Hosted` `Website Builder` `Creative`
- [Wix eCommerce](https://www.wix.com/ecommerce) - Wix eCommerce is a hosted website builder with online store functionality. It includes templates, product management, and integrated payments. E-commerce features require a paid subscription plan. ([Read more](/details/wix-ecommerce.md)) `Paid` `Hosted` `Website Builder` `SMB`

## Open-Source E-commerce

- [nopCommerce](https://www.nopcommerce.com/) - nopCommerce is an open-source e-commerce platform built on ASP.NET Core and Microsoft SQL Server. It offers a self-hosted solution with B2B and B2C features, including multi-store and mobile support. The source code is freely available. ([Read more](/details/nopcommerce.md)) `Open Source` `Self-Hosted` `.NET` `B2B` `ASP.NET`
- [OpenCart](https://www.opencart.com/) - OpenCart is an open-source PHP-based e-commerce platform for self-hosted online stores. It features a lightweight admin interface, extensions marketplace, and multi-store functionality. The core code is free to download and modify. ([Read more](/details/opencart.md)) `Open Source` `Self-Hosted` `PHP` `Lightweight`
- [PrestaShop](https://www.prestashop.com/) - PrestaShop is an open-source e-commerce platform written in PHP with a MySQL database. It provides a self-hosted solution with a modular architecture and marketplace for themes and modules. The core software is free to download and use. ([Read more](/details/prestashop.md)) `Open Source` `Self-Hosted` `PHP` `MySQL` `European`
- [Shopware](https://shopware.com/) - Shopware is an open-source e-commerce platform built with PHP and Symfony, offering headless commerce capabilities. It provides a self-hosted community edition and paid cloud editions with B2B and B2C features. Extensions and themes are available through its store. ([Read more](/details/shopware.md)) `Open Source` `Self-Hosted` `API` `PHP` `Headless`
- [WooCommerce](https://woocommerce.com/) - WooCommerce is an open-source e-commerce plugin for WordPress. It enables self-hosted online stores with extensions for payments, shipping, and subscriptions. Core software is free; hosting and extensions are paid. ([Read more](/details/woocommerce.md)) `Open Source` `Self-Hosted` `Free Plan` `WordPress` `PHP`
